# Brandspix வாடிக்கையாளர் & நிர்வாகப் போர்ட்டல்: தேவையான தகவல்கள் மற்றும் அணுகல்கள்

தயாரிக்கப்பட்டது: Brandspix நிறுவனத்திற்காக  
நோக்கம்: போர்ட்டலை உருவாக்கவும், தொடங்கவும், நடத்தவும் உங்களிடமிருந்து எங்களுக்கு என்னென்ன தேவை, அவை ஏன் தேவை, ஒவ்வொன்றும் எளிய சொற்களில் என்ன என்பதைப் பட்டியலிடுவது.

## இது எப்படி செயல்படுகிறது

- **அனைத்து கணக்குகளும் உங்கள் பெயரில் இருக்க வேண்டும்.** கீழே உள்ள கணக்குகளை நிறுவனத்தின் பெயரில் தொடங்கவும். சேவை அனுமதித்தால், எங்களை ஒரு குழு உறுப்பினராக அழைக்கலாம். உங்கள் தனிப்பட்ட கடவுச்சொற்கள் (passwords) எங்களுக்குத் தேவையில்லை, நாங்கள் கேட்கவும் மாட்டோம்.
- **ரகசியக் குறியீடுகள் பாதுகாப்பாகப் பகிரப்பட வேண்டும்.** சில சேவைகள் "API key" தரும். இது நம் மென்பொருள் அந்தச் சேவையுடன் பேச அனுமதிக்கும் ஒரு தனிப்பட்ட குறியீடு. இதை password manager அல்லது ஒருமுறை மட்டும் திறக்கும் ரகசிய இணைப்பு (one-time secret link) மூலம் பகிரவும். மின்னஞ்சல் அல்லது அரட்டை (chat) மூலம் அனுப்ப வேண்டாம்.
- **முதலில் சோதனை, பிறகு நேரலை.** பணம் செலுத்தும் சேவைகள் போலிப் பணத்துடன் கூடிய பாதுகாப்பான "test mode" வழங்குகின்றன. எல்லாவற்றையும் test mode-இல் உருவாக்கிச் சோதிப்போம். தொடக்க நாளில், உங்கள் ஒப்புதலுடன் மட்டுமே நேரலை (live) முறைக்கு மாறுவோம்.
- **நேரம் முக்கியம்.** **முன்கூட்டியே தொடங்கவும்** என்று குறிக்கப்பட்டவை மூன்றாம் தரப்பின் சரிபார்ப்பை உள்ளடக்கியவை. அதற்குச் சில நாட்கள் முதல் சில வாரங்கள் ஆகலாம்.
